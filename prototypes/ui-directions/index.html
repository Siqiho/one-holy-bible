One Holy Bible · 界面方向 Demo

三个方向都已修复审查报告中的全部 P1/P2 问题(不变淡、双语默认、节级联动、可见反馈、悬停操作、统一浮层、强焦点环),差别在于信息架构的激进程度。数据全部来自真实经文与卡片。

DEMO A · 保守

修复版工作台

保留现有三栏结构与资源库/整理卡片概念。工具栏合并为一个搜索框 + 视图切换 + 自动保存信号 + 溢出菜单;右坞顶部固定「当前经节」区,重置有确认和撤销。

 DEMO B · 结构简化(你认可的方向)

单一跟随阅读资源流

左坞取消,三个卡片区合并为右侧一条「跟随阅读」流:选中经节即滚动定位,按节分组,钉住的卡片常驻顶部。资源库变成工具栏浮层里的开关。支持 ↑↓ 逐节移动。

 DEMO C · 激进

书页边注

无坞、无卡片 chrome:一页居中的双语书页(中文为主,英文对照缩排),所选经节的注释以安静的边注浮现在右页缘,查看全部时从右侧滑出抽屉。↑↓/jk 逐节,/ 搜索,Enter 开抽屉。

 DEMO C+ · 入选方向 · 完整版

书页边注 + 三项核心能力

在 C 的骨架上加回:左侧书脊导航(卷/章/节自主选择,默认收起,节号带内容圆点);图片卡以真实图片为主呈现(边注缩略图 → 抽屉大图 → 灯箱);关联内容五层模型(本节锚定 + 范围覆盖徽标 + 抽屉「本章」纵览 + 上下文跳转)。61 张真实卡片、14 张真实图片。

建议用 1280px 以上宽度的浏览器窗口体验;三个 demo 均为独立静态页面,不影响应用代码。

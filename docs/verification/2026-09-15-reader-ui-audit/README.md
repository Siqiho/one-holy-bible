## 按钮重复与职责

- 两个搜索框可合并，但经文检索和卡片筛选能力都应保留。本轮整合界面，不将卡片搜索扩大成全部历史卡片库。
- 刷新成功/失败在顶栏与底部重复提示，顶栏提示还会挤掉操作按钮。本轮保留一份底部反馈。
- “保存布局”与自动保存重叠，保留手动再次保存入口，降低主按钮强调，并标明自动保存行为。
- 右侧卡片、中央当前节卡片、左侧整理卡片是三个不同集合；不能因标题相同就删除其中一个入口。
- 左侧移除整理、中央移除整理，与右侧退回/删除资源的作用不同，不能合并成一个无范围的删除动作。
- 原搜索框旁“全部”是状态文字，不是失效按钮。
- 模块交换按钮与拖动换位有功能重叠，但提供明确、可操作的替代入口，保留。
- 阅读模式的“阅读台”返回命名容易混淆，改为“工作台”。

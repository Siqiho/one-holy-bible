# One Holy Bible v0.3.0

This release refreshes the independent public reader from the maintained development snapshot, with the current reading views and selected public card data.

## Changes since v0.2.0

- Reading and study-workbench views, remembered reading position, and appearance controls from the current reader.
- 16,092 explanatory text cards (previously 10,963).
- 2,927 image-card placements (previously 2,705), referencing 2,735 unique PNGs (previously 2,515).
- 178 Doré chapter artworks with chapter mapping and immutable image descriptors.
- The existing 66-book, CUV/KJV, lazy-loading and whole-Bible Scripture-search packaging remains in public schema 2.

The current selected projection contains 19,018 source cards. One image spans two books and is emitted as two book-scoped placements sharing one asset; the public total is therefore 19,019 placements. Resources excluded by the current source projection remain excluded.

## Snapshot

- Development source commit: `9b015963909dedc54704bee6864d7a6de233251b`.

The development commit and generated-data hashes jointly identify the source; the generated resource projection is maintained outside Git and is not implied by the commit alone.

## Boundaries

Private editing services, source PDFs, source-positioning tools, synchronization internals, review-state metadata, and local filesystem paths are excluded. The source-import pipeline stays outside the public repository. Public reading preferences remain local to the reader; public cards are read-only.

This release updates GitHub source and image repositories. It does not update a hosted website or include a new signed desktop installer. Validation is recorded separately in [the release verification](../verification/2026-09-16-v0.3.0-public-release-verification.md); technical checks are not a new editorial review of every explanatory card.
